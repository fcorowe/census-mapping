Census Mapping

Interactive census mapping for student share, student counts, population density, and OAC classes.

GitHub Pages wrapper

This page is static and embeds a deployed Shiny app in the right panel.

How to configure:

  1. Deploy the Shiny app to a Shiny host (for example shinyapps.io).
  2. Edit docs/config.js and set SHINY_APP_URL.
  3. Push to main and enable GitHub Pages from /docs.
